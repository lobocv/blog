# Find sources for the active post

Find the active post (see "Where things live" in `AGENTS.md`). Follow
"Research and links" in `AGENTS.md`.

- Search for primary sources first: official docs, specs, the original paper or post
- Check every URL resolves before suggesting it
- Report short notes in chat, one per source:
  - The link
  - What it says that's relevant, in a line
  - Where in the post it would fit (quote the sentence it would attach to)
- 1 to 3 links per request. Fewer good links beat many
- If a claim in the post looks wrong or unsupported, say so plainly
- If nothing solid turns up, say that. Never invent a source

Don't edit the post. Calvin decides which links go in. If he says to add them,
link existing words in his sentences rather than adding new sentences.
