# Timeline Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/journey/` page where a pinned landscape scene follows a scrolling column of work chapters, with a faceted wolf that runs, rewinds and ages, and one scene (Sensors & Software radar) drawn at full quality.

**Architecture:** Chapter data and pure logic (validation, side-item placement, scroll-to-camera mapping) live in typed modules with unit tests. The Astro page renders the text column as plain HTML from the data. A client script builds the SVG scene, maps scroll to a camera position and animates transforms only. Every scene except the radar one stays as a labelled grey placeholder; the rest get their art in a follow-up plan once Calvin approves the radar style.

**Tech Stack:** Astro 7, vanilla TypeScript, inline SVG, vitest.

**Spec:** `docs/superpowers/specs/2026-11-23-timeline-design.md`

## Global Constraints

- Calvin asked to focus on work experience first: no life chapters (high school, physics to software, what's next) and no renovations or hobbies yet. The data model supports them; the data file holds none
- Colours come from tokens in `src/styles/site.css` (night in `:root`, day in `[data-time="day"]`); add new tokens there, not hard-coded colours, so day/night works without a re-render
- Animate `transform` and `opacity` only; pre-build SVG once, never rebuild per frame
- `prefers-reduced-motion: reduce`: camera jumps to each chapter, no run cycle, no prop transitions
- Text column is plain HTML from the data, readable with the script disabled
- Must work at 390px wide with a 16px side gutter and no horizontal scroll
- No em-dashes anywhere in copy. No phone number, email, coworker names, customer names, or reasons for leaving a job
- The page stays out of the nav and carries `noindex` until `TIMELINE.draft` is set to `false` by Calvin
- Do not change `src/scripts/art/landscape.js` or `src/scripts/hero/hero.js` (their `rng()` order defines existing art). Copy shapes/palette ideas, not code paths

## Review Focus

- Very tall chapter (long text) or very short one: the camera must still move smoothly and reach the next chapter exactly when its row hits the reading line. Test in Task 1 (`cameraPos` with uneven tops)
- Scrolling above the first chapter and past the last: camera clamps (no NaN, no running off the world). Test in Task 1
- Resizing or rotating the phone mid-scroll: row offsets are re-measured, camera doesn't jump to a stale chapter. Checked in Task 3 step "resize"
- Fast fling scroll on a phone: the wolf's run cycle and age cross-fade keep up without the age flickering between two chapters. Checked in Task 3
- Day/night toggle while on the page: scene colours follow the toggle with no reload. Checked in Task 4 and Task 5 screenshots

### Task 1: Timeline data model and pure logic

**Files:**
- Create: `src/data/timeline.ts`, `src/lib/timeline.ts`
- Test: `src/lib/timeline.test.ts`

**Interfaces:**
- Produces:
  ```ts
  // src/data/timeline.ts
  export type Age = 0 | 1 | 2 | 3;               // pup, yearling, adult, grey muzzle
  export type SceneId = 'fork' | 'sky' | 'radar-ground' | 'radar-sweep' | 'clouds' | 'avalanche' | 'summit' | 'ridge' | 'overlook';
  export type Month = `${number}-${string}`;     // 'YYYY-MM'
  export interface Chapter {
    id: string; kind: 'work' | 'life';
    start: Month; end?: Month;                    // end omitted = ongoing
    when: string;                                 // display, eg 'Jul 2013 – Nov 2017'
    era: string; title: string; role?: string;
    scene: SceneId; age: Age;
    paragraphs: string[]; bullets?: string[];
    link?: { href: string; label: string };
  }
  export interface SideItem { kind: 'renovation' | 'hobby' | 'project'; start: Month; end?: Month; when: string; title: string; summary: string; body?: string }
  export const TIMELINE: { draft: boolean; chapters: Chapter[]; side: SideItem[] };
  // src/lib/timeline.ts
  export function validateTimeline(t: typeof TIMELINE): string[];
  export function attachSideItems(chapters: Chapter[], side: SideItem[]): Map<string, SideItem[]>;
  export function cameraPos(tops: number[], line: number, lastBottom: number): { index: number; pos: number };
  ```

- [ ] **Step 1: Write the failing tests** in `src/lib/timeline.test.ts`:
  - `validateTimeline` returns `[]` for the real `TIMELINE`
  - flags work chapters that overlap: `{start:'2025-09', end:'2026-09'}` then `{start:'2026-08'}` → one error naming both ids. Same-month handover (`end:'2026-08'`, next `start:'2026-08'`) is allowed
  - flags chapters out of chronological order, an `age` lower than the previous chapter's, an `end` before `start`, a duplicate `id`, and any `—` in `title`, `paragraphs`, `bullets`, `summary` or `body`
  - `attachSideItems`: an item starting `2021-06` lands on the chapter whose span contains it (`2020-02`..`2024-12`); an item before the first chapter lands on the first; an item with `start` equal to a chapter's `start` lands on that chapter
  - `cameraPos([100, 400, 1000], line, 1300)`:
    - `line = 50` → `{ index: 0, pos: -0.6 * (1 - 50/100) }` (approach from before the first chapter, clamped at `-0.6`)
    - `line = 100` → `{ index: 0, pos: 0 }`; `line = 250` → `{ index: 0, pos: 0.5 }`
    - `line = 700` → `{ index: 1, pos: 1.5 }` (uneven row heights still interpolate per row)
    - `line = 5000` → `{ index: 2, pos: 3 }` (clamped at the end, no NaN)

### Task 3: Scene engine with placeholder scenes

**Files:**
- Create: `src/scripts/journey/scene.ts`, `src/scripts/journey/scenes.ts`
- Modify: `src/pages/journey.astro` (add `<script>` importing `initJourney`)

**Interfaces:**
- Consumes: DOM contract (Task 2), `cameraPos` (Task 1), `drawWolf`/`poseWolf` (Task 4; until Task 4 lands, use a grey box-and-triangle stand-in with the same signatures)
- Produces:
  ```ts
  // scene.ts
  export const GAP = 700;          // world units between chapters
  export const WOLF_X = 740;       // wolf's fixed x in the 1600-wide viewBox, near centre for the phone crop
  export function initJourney(root: HTMLElement): void;
  // scenes.ts
  export interface SceneLayers { far: SVGGElement; mid: SVGGElement; ground: SVGGElement }
  export interface SceneCtx { x0: number; x1: number; chapterX: number[] }   // world span of this scene and the chapter x positions in it
  export type DrawScene = (layers: SceneLayers, ctx: SceneCtx) => { props?: Prop[] };
  export interface Prop { el: SVGGElement; x: number; layer: 0.3 | 0.6 | 1 }  // rises in when the wolf is within 560 units
  export const SCENES: Record<SceneId, DrawScene>;
  ```

- [ ] **Step 1: Implement.** Port the grey-box's behaviour, not its code shape:
  - chapter `i` sits at world `x = 600 + i * GAP`; consecutive chapters with the same `scene` share one span
  - parallax: far `0.3`, mid `0.6`, ground `1`
  - reading line `scrollY + stageHeight + (innerHeight - stageHeight) * 0.35`; feed row tops (measured on load and on `resize`, cached between) to `cameraPos`; camera target `600 + pos * GAP - WOLF_X`; ease `cam += (target - cam) * 0.12` per frame
  - run cycle phase advances by `v * 0.06` where `v` is camera delta per frame, so scrolling up plays it backwards; wolf always faces right
  - wolf is still when `|v| <= 0.3`
  - age scale eases toward `[0.55, 0.72, 0.9, 1][age]` at `0.08` per frame
  - HUD shows the active chapter's `when` and `era`
  - rows get `seen` via `IntersectionObserver` (threshold `0.1`) and `active` for the current index
  - reduced motion: no easing, no run cycle
  - every `SceneId` except `radar-ground` draws a dashed outline with its name (the grey-box placeholder)
  - stop the `requestAnimationFrame` loop when the stage is off-screen or the tab is hidden; restart on return

- [ ] **Step 2: Verify** with `make dev` at 1280×900 and 390×844:
  - scroll down through all chapters: wolf runs, HUD changes at each row, scene outlines pass under the wolf
  - scroll up: legs run backwards, wolf keeps facing right
  - stop scrolling: wolf stands still within half a second
  - resize from desktop to phone width mid-page: the active chapter stays the same and the camera doesn't jump
  - fling-scroll on phone width: active chapter and age settle on the row at the reading line with no flicker
  - DevTools Performance: no layout or style recalculation in the frame loop

  ```ts

  ```

- [ ] **Step 1: Draw four side-on running wolves** in the hero's faceted style (flat polygons, 3 or 4 tones per body, lit from the upper right; see the `wolfFacets` approach in `src/scripts/hero/hero.js` for the look):

  Legs are separate groups so `poseWolf` can rotate them (front and back pairs swing in opposite phase, about ±18°). Body bobs `-6 * |sin(phase)|` while moving. Cross-fade: opacity of `ages[floor(age)]` and `ages[ceil(age)]` by the fraction.
